# 桌面软件前端设计观察（2026-11-03）

用 REA + 样式表提取 + 窗口截图，观察了本机在用的四款软件，目标是提炼可复用到清渠的设计规则。

## 观察对象与证据

| 软件 | 形态 | 证据 |
| --- | --- | --- |
| DeepSeek Harness 0.2.1-rc.5 | Electron | `app.asar` 58,339 项、21 个 CSS；`--dsw-*` 令牌体系、elevation/radius token、11–16px 字阶 |
| WorkBuddy 5.9.3 | Electron | 主 CSS 2,772 个变量：`--cb-*` 基础尺度 + `--wb-*` 组件层，桥接 VS Code 主题变量 |
| 夸克 7.4.2.1020 | Electron（antd） | `index.css` 1.1 MB：单墨色 + 透明度阶梯、单一品牌蓝、4/6/8/12 圆角 |
| 微信 4.1.15 | 原生 | 窗口截图（三栏结构、整行选中、未读点） |

截图见 `wechat.png`、`dsh.png`。

## 四套做法

### DeepSeek Harness
- 令牌三层：`--dsw-static-*`（原始色板）→ `--dsw-alias-*`（语义）→ `--dsw-radius-* / --dsw-elevation-soft|prominent|panel`（组件层）。
- 密度高：正文 13px、辅助 12px、代码 11px；行高 18/20/22/24；间距 4/6/8/10/12/16。
- 深色底近黑（截图取样 `#040609` / `#05080F`），分区靠 1px 边线和层级底色，不靠大阴影。
- 选中态用单一琥珀色（取样 `#BC6C10`）整行强调；滚动条、焦点环都有独立 token。
- 字号有 `--dsh-content-font-size` 和 delta 变量，支持用户调字号。

### WorkBuddy
- 基础尺度显式命名：`--cb-spacing-xs…xxl` = 4/8/12/16/20/24；`--cb-border-radius-sm…2xl` = 4/6/8/16/24。
- 组件层再套 `--wb-*`（1,990 个），避免组件里写死数值。
- 通过 `--cb-vscode-* → var(--vscode-*)` 继承宿主主题，同一套 UI 能跟着编辑器换肤。
- 正文 12/13/14，标题 15/16；hover/边框用低透明度黑。

### 夸克
- 一个墨色 `#060a26` + 透明度阶梯：`0a`(4%)、`0f`(6%)、`1f`(12%)、`3d`(24%)、`66`(40%)、`80`(50%)、`cc`(80%)。
- 一个品牌色 `#0d53ff`，hover 只提亮到 `#3675ff`；其余全是中性色。
- 圆角 2/4/6/8/12；正文 12/13/14；行高 18/20/24，密集表格也用 20。
- 阴影极少：`0 2px` 级别；分区靠 `1px` 浅边线和底色差。

### 微信
- 三栏：62px 图标栏 → 250px 会话列表 → 内容区；列表行约 64px。
- 选中行整行实色（取样 `#15AC70`）；未选中列表底 `#E6E6E8`、内容底 `#FAFAFA`。
- 时间 12px 灰、未读是 18px 小圆点、静音是独立小图标；信息层级只靠字重/灰度/小徽标。
- 顶部搜索框占满列表宽度；标题栏 48–56px。

## 共性（可直接照搬）

1. **令牌分层**：原始色板 → 语义角色 → 组件值。不要在页面里写死颜色和间距。
2. **一个强调色**：微信绿 / DSH 琥珀 / 夸克蓝。强调色只给选中、主按钮、未读、关键状态。
3. **墨色 + 透明度**：中性色用一个墨色加 6–8 档透明度，比堆十几个灰更好维护。
4. **4/8 网格**：间距 4/8/12/16/20/24；表格行 36–44；页头 44–56；卡片圆角 4–8。
5. **字号收敛**：11/12/13/14/16 五档足够；行高 18/20/22/24；数字用等宽（tabular）。
6. **扁平 + 1px 边线**：阴影只给浮层（菜单/弹窗/抽屉），列表 hover 用 4% 墨色底。
7. **三栏是桌面端的默认骨架**：窄图标栏 + 列表栏 + 内容区；页内不再重复标题。

## 清渠落地口径（建议）

| 项 | 取值 |
| --- | --- |
| 墨色 | `#0B1F2A`，透明度 4/6/12/24/40/50/80% |
| 页面底 | `#F4F8F9`，卡片 `#FFFFFF` |
| 边线 | `#DCE6E9`，hover 边线 `#C6D6DA` |
| 强调色 | 水务青 `#0E7C74`，hover `#0B6A63`，浅底 `#E7F3F1` |
| 状态 | 红 `#C0392B`、琥珀 `#B7791F`、绿 `#2E7D32`（只做状态） |
| 字号 | 11/12/13/14/16/20/24；行高 16/18/20/22/24/28/32 |
| 间距 | 4/8/12/16/20/24/32；页边距 24；卡片内边距 16 |
| 圆角 | 卡片 6、输入 4、弹层 8；不要大圆角胶囊 |
| 表格 | 行高 40、表头 36、数字右对齐、等宽数字 |
| 阴影 | 只给弹层：`0 8px 24px rgba(11,31,42,.12)`；卡片用 1px 边线 |
| 布局 | 左栏 232、页头 44、内容区最大 1440；驾驶舱单行指标带 + 细线分区 |
